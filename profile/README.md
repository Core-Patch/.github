# Core & Patch

A Core & Patch desenvolve software, produtos digitais e soluções tecnológicas.

Este é o perfil da organização no GitHub. Os repositórios têm escopos e ciclos de manutenção próprios; consulte o README e as instruções de cada projeto antes de contribuir.

## Projetos e referências

- [Website institucional](https://github.com/Core-Patch/core-patch-website)
- [CoreHub](https://github.com/Core-Patch/CoreHub) — plataforma interna de operação
- [Core Knowledge](https://github.com/Core-Patch/Core-Patch-core-knowledge) — conhecimento e decisões governadas

Os templates públicos de contribuição estão neste repositório. Documentos internos, contratos, dados de clientes e segredos não são publicados aqui.
