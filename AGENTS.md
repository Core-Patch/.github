# Community repository — contributor guidance

This repository is **public** and contains the organization profile and reusable GitHub community templates.

Before changing anything, read the relevant Issue and `README.md`. Work on a topic branch, keep changes focused, open a Pull Request, verify Markdown/YAML and links, respond to inline review comments, and merge only after applicable approval. Never include private organizational policies, client information, secrets, incident details or unverified contact channels.

This repository does not govern the code or architecture of other projects. Their local instructions and approved policies remain authoritative.
